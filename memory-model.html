29.7.4 Sequentially Consistent Atomics sec-memory-order

For events readEvent and writeEvent such that readEvent reads-from writeEvent in execution, there is no WriteSharedMemory or ReadModifyWriteSharedMemory event value in SharedDataBlockEventSet(execution) such that value.[[Order]] is seq-cst, writeEvent is-memory-order-before value in execution, value is-memory-order-before readEvent in execution, and any of the following conditions are true.
