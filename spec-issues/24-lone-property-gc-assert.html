24. CompileToCharSet asks UnicodeMatchPropertyValue for a General_Category value before testing that it is one

Location
§22.2.2.9 CompileToCharSet (#sec-compiletocharset), UnicodePropertyValueExpression :: LoneUnicodePropertyNameOrValue, step 2, with §22.2.2.9.8 UnicodeMatchPropertyValue (#sec-runtime-semantics-unicodematchpropertyvalue-p-v), step 2.
Kind
failing Assert (for every lone binary property name), and a condition that is true whenever it is defined.
Model erratum
LonePropertyGeneralCategoryAssert, default reading test262; its readings: literal, test262, proposed. The test262 and proposed readings are the same step 2, the proposed wording below; under the literal reading the model stops where UnicodeMatchPropertyValue's Assert fails.
Upstream
Checked 2026-11-19: issue #3586 (open, 2025-05), "UnicodeMatchPropertyValue assertion fails by UnicodePropertyValueExpression", reports it for /[\p{Hex}]/u; PR #3587 (open, 2025-05), "Editorial: Fix incorrect use of UnicodeMatchPropertyValue", fixes it by testing s first, with other changes (Script_Extensions), and is not merged.
On this site
LonePropertyGeneralCategoryAssert on Spec issues & errata (defect of the text; SpecTec bakes in the test262 reading)

Text

CompileToCharSet, UnicodePropertyValueExpression :: LoneUnicodePropertyNameOrValue:

1. Let s be the source text matched by LoneUnicodePropertyNameOrValue.

2. If UnicodeMatchPropertyValue(General_Category, s) is a Unicode property value or property value alias for the General_Category (gc) property listed in PropertyValueAliases.txt, then

a. Return the CharSet containing all Unicode code points whose character database definition includes the property “General_Category” with value s.

3. Let p be UnicodeMatchProperty(regexpRecord, s).

4. Assert: p is a binary Unicode property or binary property alias listed in the “Property name and aliases” column of …, or a binary Unicode property of strings listed in the “Property name” column of ….

UnicodeMatchPropertyValue (p: ECMAScript source text, v: ECMAScript source text), returning a Unicode property value:

2. Assert: v is a property value or property value alias for the Unicode property p listed in PropertyValueAliases.txt.

3. Let value be the canonical property value of v as given in the “Canonical property value” column of the corresponding row.

Problem

Step 2 calls UnicodeMatchPropertyValue before it tests s. For a lone binary property name (\p{ASCII}, \p{Any}, \p{Hex}, or a property of strings such as \p{RGI_Emoji} with the v flag), s is no General_Category value, and UnicodeMatchPropertyValue's Assert (step 2) fails. Steps 3–4, which handle exactly these names, are never reached. Where the call does return, it returns a canonical General_Category value, so step 2's test is always true; and step 2.a uses s, which may be an alias (Lu), as the value, not the canonical value the call computed. (Note also that step 2.a returns the raw General_Category CharSet directly without calling MaybeSimpleCaseFolding(_regexpRecord_, _charSet_) as the two-part General_Category=... branch and binary-property step 5 do, so /\P{Lu}/vi.test("A") differs from /\P{gc=Lu}/vi.test("A").)

Examples

examples/24-lone-property-gc-assert.js (outputs: the recorded runs):

/\p{Lu}/u.test("A");          // a General_Category value
/\p{ASCII}/u.test("a");       // binary properties
/\p{Hex}/u.test("f");
/\p{Any}/u.test("\u{10FFFF}");
\p{Lu} \p{ASCII}, \p{Hex}, \p{Any}

V8, SpiderMonkey, JavaScriptCore true true
formal model (test262 reading) true true
formal model (literal reading) true stop: erratum LonePropertyGeneralCategoryAssert sec-runtime-semantics-unicodematchpropertyvalue-p-v#0 2

Under the literal reading the example stops at its first binary property and prints only the stop line; \p{Lu} alone prints true.

Proposed wording

Proposed: test s first, then take the canonical value from UnicodeMatchPropertyValue.

test262

The binary-property files of built-ins/RegExp/property-escapes/generated/ (53 of them: ASCII.js, Any.js, Hex_Digit.js, …) and those of its strings/ directory (properties of strings, with the v flag) compile a lone binary property name; under the literal text each reaches the Assert. An Assert has no observable effect, so none fails.

The program

The example is a Script. Its runs on the engines and on the model: the examples' runs.

Source examples/24-lone-property-gc-assert.js
// CompileToCharSet, UnicodePropertyValueExpression :: LoneUnicodePropertyNameOrValue, step 2 calls
// UnicodeMatchPropertyValue(General_Category, s) before testing s; for a binary property name s its
// Assert (step 2) fails.
if (typeof print === "undefined") globalThis.print = console.log;
var cases = [
  ["/\\p{Lu}/u.test('A')", () => /\p{Lu}/u.test("A")],
  ["/\\p{ASCII}/u.test('a')", () => /\p{ASCII}/u.test("a")],
  ["/\\p{Hex}/u.test('f')", () => /\p{Hex}/u.test("f")],
  ["/\\p{Any}/u.test('\\u{10FFFF}')", () => /\p{Any}/u.test("\u{10FFFF}")],
];
for (var [src, run] of cases) {
  try { print(src + ": " + run()); } catch (e) { print(src + ": " + e.constructor.name); }
}
