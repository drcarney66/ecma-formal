Spec issues & errata · defect of the text · docs/spec-issues/35-contains-awaitexpression-cover.md

35. Contains never finds an |AwaitExpression|: async function f(x = await 1) {} has no early error

Location
§8.5.1 Static Semantics: Contains (#sec-static-semantics-contains), the default definition, step 1.a, and its rows; §13.5 Unary Operators (#sec-unary-operators), UnaryExpression's grammar and Supplemental Syntax; the six rules "… Contains |AwaitExpression| is true" of §15.3.1 (ArrowFunction), §15.6.1 (AsyncGeneratorMethod, AsyncGeneratorDeclaration/Expression), §15.8.1 (AsyncMethod, AsyncFunctionDeclaration/Expression) and §15.9.1 (AsyncArrowFunction).
Kind
missing case (no Contains row for a cover); six early errors never apply.
Model erratum
ContainsAwaitCover, default reading test262; its readings: literal, test262, proposed. The test262 and proposed readings count UnaryExpression : CoverAwaitExpressionAndAwaitUsingDeclarationHead (and not the cover of an |AwaitUsingDeclaration|) as an |AwaitExpression|.

Text

An await expression parses as the cover:

UnaryExpression[Yield, Await] : … [+Await] CoverAwaitExpressionAndAwaitUsingDeclarationHead[?Yield]

CoverAwaitExpressionAndAwaitUsingDeclarationHead[Yield] : await UnaryExpression[?Yield, +Await]

and |AwaitExpression| is only its refined interpretation (Supplemental Syntax):

When processing an instance of the production UnaryExpression : CoverAwaitExpressionAndAwaitUsingDeclarationHead the interpretation of CoverAwaitExpressionAndAwaitUsingDeclarationHead is refined using the following grammar: AwaitExpression[Yield] : await UnaryExpression[?Yield, +Await]

Contains has no row for that production, so the default definition applies:

1. For each child node child of this Parse Node, do

a. If child is an instance of symbol, return true.

b. If child is an instance of a nonterminal, then

i. Let contained be the result of child Contains symbol.

ii. If contained is true, return true.

2. Return false.

The rules (one of each form):

It is a Syntax Error if ArrowParameters Contains AwaitExpression is true.

It is a Syntax Error if FormalParameters Contains AwaitExpression is true.

It is a Syntax Error if CoverCallExpressionAndAsyncArrowHead Contains AwaitExpression is true.

Problem

No parse tree has an |AwaitExpression| node: the parse produces the cover, and no rule makes it "cover" an |AwaitExpression| except when the production is "processed", as Evaluation does ("Let expr be the |AwaitExpression| that is covered by …"). Step 1.a compares each child with symbol; the child of UnaryExpression : CoverAwaitExpressionAndAwaitUsingDeclarationHead is a |CoverAwaitExpressionAndAwaitUsingDeclarationHead|. So "X Contains |AwaitExpression|" is false for every X and the six rules never apply: read literally, async function f(x = await 1) {} is a function whose parameter initializer awaits.

The other covers have Contains rows that look through them (ArrowParameters : CoverParenthesizedExpressionAndArrowParameterList, AsyncArrowFunction : CoverCallExpressionAndAsyncArrowHead `=>` AsyncConciseBody). Were |AwaitExpression| itself a right-hand side of UnaryExpression, step 1.a would find it. |YieldExpression| has no cover, and the "Contains |YieldExpression|" rules work.

The row is for the UnaryExpression production only: under AwaitUsingDeclaration : CoverAwaitExpressionAndAwaitUsingDeclarationHead BindingList `;` the cover is an |AwaitUsingDeclarationHead|. (Note a companion gap in §15.9.1: AsyncArrowFunction's early error checks unrefined |CoverCallExpressionAndAsyncArrowHead| Contains |AwaitExpression|, whereas in [~Await] contexts async (x = await + 1) => x parses await + 1 as binary + inside CoverCallExpressionAndAsyncArrowHead and only becomes an AwaitExpression inside the refined |AsyncArrowHead|.)

Proposed wording

A Contains row beside the other covers' rows:

--- a/spec.html
+++ b/spec.html
@@ -9550,6 +9550,12 @@
       <emu-alg>
         1. Let _formals_ be the |ArrowFormalParameters| that is covered by |CoverParenthesizedExpressionAndArrowParameterList|.
         1. Return _formals_ Contains _symbol_.
+      </emu-alg>
+      <emu-grammar>UnaryExpression : CoverAwaitExpressionAndAwaitUsingDeclarationHead</emu-grammar>
+      <emu-alg>
+        1. If _symbol_ is |AwaitExpression|, return *true*.
+        1. Let _expr_ be the |AwaitExpression| that is covered by |CoverAwaitExpressionAndAwaitUsingDeclarationHead|.
+        1. Return _expr_ Contains _symbol_.
       </emu-alg>
       <emu-grammar>
         AsyncArrowFunction : `async` AsyncArrowBindingIdentifier `=>` AsyncConciseBody

The program

The example is a Script. Its runs on the engines and on the model: the examples' runs.

Source examples/35-contains-awaitexpression-cover.js
// Contains (§8.5.1) has no row for UnaryExpression :
// CoverAwaitExpressionAndAwaitUsingDeclarationHead, the production an `await`
// expression parses as, so literally no Parse Node contains an
// AwaitExpression and the rules "FormalParameters Contains AwaitExpression"
// never apply. Each source is evaluated as a Script (indirect eval) or by the
// AsyncFunction constructor; test262 expects a SyntaxError for the first six
// and none for the last three.
if (typeof print === "undefined") globalThis.print = console.log;
var AsyncFunction = (async function () {}).constructor;
var cases = [
  ["async function f(x = await 1) {}", () => (0, eval)("async function f(x = await 1) {}")],
  ["(async function* (x = await 1) {})", () => (0, eval)("(async function* (x = await 1) {})")],
  ["({ async m(x = await 1) {} })", () => (0, eval)("({ async m(x = await 1) {} })")],
  ["({ async *m(x = await 1) {} })", () => (0, eval)("({ async *m(x = await 1) {} })")],
  ["async function g() { async (x = await 1) => 0; }", () => (0, eval)("async function g() { async (x = await 1) => 0; }")],
  ["AsyncFunction('x = await 1', '')", () => AsyncFunction("x = await 1", "")],
  ["async function h() { await 1; }", () => (0, eval)("async function h() { await 1; }")],
  ["async function k(x = function () { var await; }) {}", () => (0, eval)("async function k(x = function () { var await; }) {}")],
  ["(async function () { class C { static { } } })", () => (0, eval)("(async function () { class C { static { } } })")],
];
for (var [src, run] of cases) {
  try { run(); print(src + ": no error"); }
  catch (e) { print(src + ": " + e.constructor.name); }
}
