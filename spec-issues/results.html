The examples' runs

Every example of the write-ups, run on the three engines and on the model: each run's exit status, standard output and standard error, exactly as recorded by scripts/spec_issues_run.py. The model's runs were made from this repository's build; the engines' runs are the record of the versions below.

Each run's exit status, standard output and standard error, exactly (absolute paths shortened).

Engine Version
V8 (node) v24.18.1 (V8 13.6.233.17-node.50)
SpiderMonkey (js140) JavaScript-C140.13.0
JavaScriptCore (bun) Bun 1.3.13+bf2e2cecf (JavaScriptCore of oven-sh/WebKit 4d5e75ebd84a14edbc7ae264245dcd77fe597c10)
the formal model (ecma-run) .lake/build/bin/ecma-run built from the checkout (its sources: the README)

A .js example is a Script: SpiderMonkey runs the file; node and bun run script-shim.cjs, which evaluates it with vm.runInThisContext (a Script in the main realm, not CommonJS or a Module):

// Evaluates the file named by argv[2] as a Script (ScriptEvaluation) in this realm.
const fs = require("node:fs"), vm = require("node:vm");
const file = process.argv[2];
vm.runInThisContext(fs.readFileSync(file, "utf8"), { filename: file });

A directory's main.mjs is a Module (node main.mjs, bun main.mjs, js140 -m main.mjs), run in the directory; the model runs Scripts only, on ecma-run's fixed host, which defines print.
