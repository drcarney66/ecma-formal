38. OrdinarySetWithOwnDescriptor asserts what a Proxy receiver's trap need not tell

Location
§10.1.9.2 OrdinarySetWithOwnDescriptor (#sec-ordinarysetwithowndescriptor), step 2.d.i, against §10.5.5 [[GetOwnProperty]] of a Proxy exotic object (#sec-proxy-object-internal-methods-and-internal-slots-getownproperty-p), steps 10.a–e.
Kind
failing Assert (or, read on the receiver's own properties only, a vacuous one).
Model erratum
OrdinarySetReceiverHasProperty, baked-in SpecTec reading proposed (spec/spectec/clauses/S10.spectec, line 190). Literal step 2.d.i (Assert: _receiver_ does not currently have a property _propertyKey_) fails both when a Proxy receiver's getOwnPropertyDescriptor trap hides a configurable target property and when an ordinary _receiver_ inherits _propertyKey_ from its prototype chain; SpecTec silences step 2.d.i with assert pass instead of checking the literal Assert:.

Text

OrdinarySetWithOwnDescriptor:

2. If IsDataDescriptor(ownDesc) is true, then

a. If ownDesc.[[Writable]] is false, return false.

b. If receiver is not an Object, return false.

c. Let existingDesc be ? receiver.[[GetOwnProperty]](propertyKey).

d. If existingDesc is undefined, then

i. Assert: receiver does not currently have a property propertyKey.

ii. Return ? CreateDataProperty(receiver, propertyKey, value).

[[GetOwnProperty]] of a Proxy exotic object, after its getOwnPropertyDescriptor trap returns undefined:

10. If trapResultObj is undefined, then

a. If targetDesc is undefined, return undefined.

b. If targetDesc.[[Configurable]] is false, throw a TypeError exception.

c. Let extensibleTarget be ? IsExtensible(target).

d. If extensibleTarget is false, throw a TypeError exception.

e. Return undefined.

Problem

The Assert rests on the answer receiver.[[GetOwnProperty]] gave one step before. For an ordinary receiver that answer is the receiver's own property, and the Assert holds. For a Proxy receiver it is the trap's answer, and step 10.e lets the trap report undefined for a configurable property of an extensible target. Then step 2.d.i either reads "have a property" as the receiver's own properties, which a Proxy exotic object does not hold, so the Assert holds for every Proxy and says nothing; or it looks through the Proxy to its target, which has the property, so the Assert fails in a conforming execution. Neither reading makes it a useful invariant, and step 2.d.ii does not need it: CreateDataProperty calls receiver.[[DefineOwnProperty]], which handles a property that exists.

Examples

examples/38-ordinaryset-receiver-has-property.js (outputs: the recorded runs):

var t = { x: 1 };
var p = new Proxy(t, { getOwnPropertyDescriptor() { return undefined; } });
print(Reflect.set({}, "x", 5, p));
print(t.x);

Reflect.set reaches step 2 with ownDesc the default data descriptor of step 1.c ({} and its prototypes have no x) and receiver p; the trap answers undefined while t has x, and CreateDataProperty redefines t.x through the Proxy.

Reflect.set(...) t.x

V8, SpiderMonkey, JavaScriptCore true 5
formal model (the Assert not checked) true 5

Proposed wording

--- a/spec.html
+++ b/spec.html
@@ -13129,7 +13129,7 @@
             1. If _receiver_ is not an Object, return *false*.
             1. Let _existingDesc_ be ? <emu-meta effects="user-code">_receiver_.[[GetOwnProperty]](_propertyKey_)</emu-meta>.
             1. If _existingDesc_ is *undefined*, then
-              1. Assert: _receiver_ does not currently have a property _propertyKey_.
+              1. NOTE: If _receiver_ is a Proxy exotic object, its target may have a property _propertyKey_.
               1. Return ? CreateDataProperty(_receiver_, _propertyKey_, _value_).
             1. If IsAccessorDescriptor(_existingDesc_) is *true*, return *false*.
             1. If _existingDesc_.[[Writable]] is *false*, return *false*.

(Deleting the step, with no note, would do as well.)

test262

None found makes a receiver's getOwnPropertyDescriptor trap hide a target property on this path (built-ins/Reflect/set and built-ins/Proxy/set use ordinary receivers or a forwarding trap). An Assert has no observable effect, so no test fails under either reading.

The program

The example is a Script. Its runs on the engines and on the model: the examples' runs.

Source examples/38-ordinaryset-receiver-has-property.js
// OrdinarySetWithOwnDescriptor 2.d.i asserts that the receiver "does not currently have" the property right
// after a Proxy receiver's trap said undefined for a property its target has.
if (typeof print === "undefined") globalThis.print = console.log;
var t = { x: 1 };
var p = new Proxy(t, { getOwnPropertyDescriptor() { return undefined; } });
print(Reflect.set({}, "x", 5, p));
print(t.x);
