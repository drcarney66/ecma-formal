Write-up 36: IsLabelledFunction tests a |Statement| node for being a |LabelledStatement|: always false →

§14.13.2 Static Semantics: IsLabelledFunction, steps 1 and 2

If stmt is not a LabelledStatement, return false. … Let item be the LabelledItem of stmt.

Formalization note

"the X of n" names a child of n (§5.1.2 gives a node only its right-hand side's children), so IsLabelledFunction 1-2 never find the LabelledStatement under a Statement node: read by §5.1.2 alone, step 1 returns false for every Statement node and if (1) l: function f() {} is valid; test262's labelled-fn-stmt*.js require a SyntaxError. The model reads "n is a X" through the unit chain, so its literal reading passes step 1 and stops (a sort error) at step 2, where n's production has no X. The test262 and proposed reading: X is taken from the first node of n's unit chain whose production has one.
